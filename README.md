## Engineering principles

I care about more than getting a model to produce an answer.

I try to build systems where:

- critical calculations remain deterministic;
- model actions are explicitly bounded;
- outputs can be traced back to evidence;
- invalid model behaviour fails visibly;
- tests cover both happy paths and failure modes;
- architecture stays simple until complexity is justified.
